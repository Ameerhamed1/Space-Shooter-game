## 🎮 Features & Gameplay Mechanics

- **Standalone Playability:** Zero-setup launcher. Users can experience the full game immediately without needing a local development environment.
- **Dynamic Spawn & AI System:** Fully automated and randomized enemy deployment with increasing difficulty metrics based on user performance.
- **Precision Collision Matrix:** High-accuracy boundary and bounding-box collision detection between multiple elements (Player, Lasers, and Enemy fleets).
- **Comprehensive State Management:** Custom HUD layout rendering changing integer parameters including lives, scores, and active difficulty levels instantly.

---

## 🛠️ Architecture & Tech Stack

- **Core Language:** Python 3.x
- **Development Standards:** Focus on Clean Code, Modular Design, and Object-Oriented Design Patterns (OOP).
- **Core Concepts Applied:**
  - **Game Loop Engineering:** Synchronized frame-by-frame asset updates and event handling.
  - **Encapsulation:** Segregated logical classes for handling distinct object identities (Spaceships, Lasers).
